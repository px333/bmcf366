# bmcf.366 portfolio

A static, responsive portfolio for selected Android programming projects.

## Files
- `index.html` — portfolio page
- `style.css` — visual styling
- `assets/` — optimized screenshots
- `favicon.svg` — site icon

## Publishing
Upload the contents of this folder to any static web host, such as GitHub Pages, Netlify, Cloudflare Pages, or similar.

## PXTool APK
The PXTool section currently links to the documentation Telegram channel and clearly notes that a direct APK URL can be added. Replace that button with a direct APK URL (or add an APK asset and an HTML download link) when a public distribution URL is available.
