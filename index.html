03 / Android utility

PXTool — Graphics, Config & Device Diagnostics

A compact Android utility combining performance controls with technical configuration tooling. It can unlock FPS and graphics options, work with texture settings, encode/decode encrypted configuration CVar data in a text-editor workflow, and present key device-health metrics with clear safety indicators and an overall performance score.
